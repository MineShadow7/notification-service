# User Notification 
## Микросервис для отправки уведомлений пользователям.

* Уведомления хранятся в базе данных.
* Отправляются пользователям по электронной почте.
* Связь с другими микросервисами осуществляется через Kafka.
* Использован фреймворк Spring Boot для разработки микросервиса.
* Использован PostgreSQL для хранения данных уведомлений.
* Использован Docker для контейнеризации микросервиса.
* Использование circuit breaker для обеспечения устойчивости микросервиса.

# Поддерживает только отправку уведомлений по электронной почте.
